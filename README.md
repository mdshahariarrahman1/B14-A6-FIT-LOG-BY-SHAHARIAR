# 🏋️ B14-A6-FIT-LOG

Fit Log is a simple workout planning web application where users can explore workouts and create their daily workout plan.

🔗 **Live Link:** Add your Vercel live link here

🔗 **GitHub Repository:** https://github.com/mdshahariarrahman1/B14-A6-FIT-LOG-BY-SHAHARIAR


## 🛠️ Technologies Used

* Next.js
* React
* TypeScript
* Tailwind CSS
* Next.js App Router
* LocalStorage

## ✨ 5 Key Features

1. **Workout Library** — Browse different workout and lift information.
2. **My Plan** — Add and remove workouts from today's plan.
3. **LocalStorage** — Saved plan data stays after page reload.
4. **Search Workout** — Search workouts by name or tag.
5. **5 Lifts Limit** — Users can add maximum 5 lifts to today's plan.
